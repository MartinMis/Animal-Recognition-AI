# Animal Recognition AI
> [!NOTE]
> You might have noticed this repository has almost no history. This is intentional as this repository serves as a publicly presentable view of a project originally developed in private repository.
> History has been omitted to prevent leaking of private information.


This project was originaly created in the team of 3 members as a second project for the neural networks class. Project implement modified AlexNet neural network to classify animals from the
[Animals-10](https://www.kaggle.com/datasets/alessiocorrado99/animals10) dataset. Project also does explorartory data analysis. In addition to training the model, the project also explores the effects
of under and over sampling.

## Repository structure
1. **data (folder)** - contains our input dataset 
   1. **raw-img** - folder that contains other folders; each one represents given class
   2. **translate.py** - script to rename folder names (original dataset had italian names)
2. **EDA.ipynb** - notebook with exploratory data analysis and our initial plans for the project
3. **model.ipynb** - notebook with our model architecture
4. **requirements.txt**
